# KPSimpleBackup
It's a simple KeePass plugin that backs up your password database to one or more locations you choose. It does this every time you save your database or whenever you choose to do it manually. It also keeps a certain number of the most recent backup.

---

**Note: I don't accept responsibility for any data loss!**  
(However, the original database file should not be touched by this plugin. To prevent data loss, don't disable the usage of the recycle bin!)
